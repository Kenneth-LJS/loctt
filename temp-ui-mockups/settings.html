Task types

Categorise tasks (Bug, Feature, Task, etc.). Each type can have its own icon and color.

Labels

Label registry. Labels can be created inline from task UIs. Setting an unknown label on a task fails — register it here first.

Milestones

Named release markers with optional target dates. Not time-boxed — for that, use Sprints. Archived milestones hide from pickers.

Relationship types

Forward/inverse pairs. There is no built-in parent/child concept — declare one here if you want it. The ranked flag enables drag-reorder of links of that type within a task.
⋮⋮ blocks↔is blocked by ranked timeline arrows
⋮⋮ relates to↔relates to
Pick one relationship type as the Timeline's dependency arrow source in Timeline defaults below.

Saved views

Workspace-shared filters from queries.yaml. Each view has a stable ID — renaming the display name doesn't break sidebar pins.
In progress status = doing or status = in_review sort: priority desc
Stale (no update > 14d) updated_at < today - 14d and status != done sort: updated_at asc
High-prio bugs type = bug and priority in (high, critical) sort: created_at desc
Built-in dynamic filters (Assigned to me, Due this week, etc.) are parameterised by the active user and not stored here.
