WEB-128

Implement Gantt edge-drag handles

Description Click to edit
Saved · just now

The Gantt bars currently support whole-bar drag (T-126), but resizing from the edges to change only start_date or due_date isn't wired up.

Acceptance criteria:

  • Hovering near the bar edge shows a resize cursor.
  • Dragging the left handle updates only start_date; right handle updates only due_date.
  • Edge drag respects the day/week/month snap from the active zoom.
  • Optimistic update; revert + toast on PATCH failure.

Reuse the dnd-kit modifiers from the whole-bar drag — see useGanttDrag().
